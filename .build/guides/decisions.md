# Decisions

An append-only, ADR-lite log of design decisions recorded while building this project. Entries
are filed automatically once a recorded decision (a discussion resolution, or an explicit
"Remember this") is approved — never hand-authored from scratch.

Before proposing a design, read this file; do not re-open a recorded decision without saying
so.

Each entry:

```
## <date> — <short title> (Goal #<n>)
Decision: <what was decided>
Rationale: <why>
Alternatives rejected: <what else was considered, and why not>
```
